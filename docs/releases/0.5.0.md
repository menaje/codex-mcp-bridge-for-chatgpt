# Codex MCP Bridge for ChatGPT 0.5.0

This release replaces the external MCP transport and tool contracts with the
2026-07-28 protocol. It is a breaking release: the bridge serves one current
contract and does not retain a legacy server, automatic downgrade, hidden input
parser, old tool alias, or compatibility card resource.

## MCP transport

- HTTP and stdio use the stable MCP TypeScript SDK v2 server entry points with
  legacy serving explicitly rejected.
- Every current request carries its protocol version, client identity, and
  capabilities in the request envelope. `server/discover` advertises only
  `2026-07-28`.
- Current list responses and discovery use private, zero-TTL cache hints. Tool
  and resource list-change subscriptions use `subscriptions/listen` rather than
  the retired HTTP session and replay paths.
- Legacy initialization, MCP session IDs, GET/DELETE transport operations,
  Last-Event-ID replay, and the old stateful transport settings are removed.
- Host, supplied Origin, and configured Bearer authentication are checked before
  MCP dispatch. Origin-free native and Tunnel requests remain supported.

## Tool and card contracts

- Tool schemas are emitted through the SDK v2 JSON Schema 2020-12 path. The old
  object-union workaround and dual model-policy transport are removed.
- `codex_task` accepts input contract 3 with the descriptor's exact
  `executionEnvelopeRef`; its result contract remains version 2.
- `codex_models` accepts only the optional `refresh` flag and always returns one
  current response form.
- Model-visible next actions are closed structured values for approved read or
  opener tools, or plain user guidance. They cannot name arbitrary tools or
  inject mutation arguments.
- The selected UI inventory contains one immutable Settings, Activity,
  Dashboard, and Question resource. Previous aliases and card URIs are not
  served by this release.

The current descriptor inventory is 26 tools: 12 model-visible and 14 app-only.
Persisted projects, settings, Activities, Agents, Jobs, questions, results, and
logical request idempotency remain in the shared application service and SQLite
state contract.

## Migration

Update MCP clients to protocol 2026-07-28 before installing this release. After
installation, restart the bridge and Secure MCP Tunnel, refresh the ChatGPT
connection so it performs discovery again, and reopen the current cards. Calls
that still use legacy initialization, session transport, retired task/model
arguments, tool aliases, or previous card URIs are rejected and are not
automatically translated.

Candidate and development builds continue to use their separate state profiles.
Follow the state upgrade and recovery runbook before deliberately selecting a
stable or absolute operational database.

## Validation

The release checks cover a clean SDK v2 dependency installation, TypeScript
build and tests, App Server schema compatibility, macOS tests, release metadata,
current HTTP and stdio behavior, tool and resource discovery, cache/result
fields, deterministic tool order, subscription close and reopen, legacy and
malformed request rejection, and Host/Origin/Bearer boundaries. Final release
acceptance also requires one real ChatGPT discovery, tool call, and card open
through the candidate's Secure MCP Tunnel.

Choose the DMG matching the Mac: `macOS-arm64-unnotarized.dmg` for Apple Silicon
