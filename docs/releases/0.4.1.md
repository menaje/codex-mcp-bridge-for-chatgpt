# Codex MCP Bridge for ChatGPT 0.4.1

This patch fixes the native macOS menu-bar window after Dashboard content changes.
The generic npm server and the existing runtime, Settings, task, and state
compatibility contracts remain unchanged.

## Menu-bar Dashboard

- The window now keeps its top edge at the menu bar while content expands or
  collapses below it. Opening a status panel grows the lower edge; closing the
  panel removes unused space instead of leaving a centered fixed-height frame.
- Long Dashboard lists remain constrained to the available display height. Only
  the detail list scrolls, so the bridge summary and footer controls stay visible.
- The implementation handles an AppKit host that has already resized around its
  center, native-host padding, secondary-display placement, and a fresh anchor
  when the menu is reopened.

## Validation

The native tests exercise short and long content, expansion and collapse,
host-padding sizing, secondary placement, and reopening. The release process now
also records a non-publishing stable-promotion rehearsal before an RC is made
public, preserving the final candidate identity through the later payload checks.

## Downloads

Choose the DMG matching the Mac: `macOS-arm64-unnotarized.dmg` for Apple Silicon
or `macOS-x64-unnotarized.dmg` for Intel. Both macOS apps are ad-hoc signed and
not Apple-notarized. The release also includes the generic npm archive, its
SHA-256 file, and `SHA256SUMS.txt`.
