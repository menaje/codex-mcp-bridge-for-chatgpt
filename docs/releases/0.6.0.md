# Codex MCP Bridge for ChatGPT 0.6.0

This release coordinates directly observed Codex results with automatic Relay completion notices. It also removes a previous filename-based admission restriction; review the project access settings before using the updated server or macOS app.

## Direct results and Relay

- An actual, bounded exact-Job wait temporarily gives the originating conversation priority over an unsent Relay completion. Ending or aborting the wait does not cancel the Job, and an unsent event becomes eligible again after the finite grace period.
- After reviewing a complete exact result, the model can confirm that exact event. This postpones its unsent notice for 60 seconds; it does not establish that the final answer was posted or that the Activity is complete. Relay delivery already entered, uncertain or accepted is never retried solely because the hold expires.
- Existing stops, project access and result retention remain authoritative. Host teardown can delay recovery until a valid Relay connection returns. Conversation-wide duplicate-free or loss-free delivery is not guaranteed.

## Breaking admission change

Project filename scanning no longer blocks Codex task admission. File access follows the configured project and execution permissions. Refresh ChatGPT connector discovery after updating and review the intended project access. The retired `CODEX_MCP_BRIDGE_DISABLE_SECRET_SCAN` and `CODEX_GPT_BRIDGE_DISABLE_SECRET_SCAN` environment variables are ignored.

## Distribution

The release contains a generic npm server archive and macOS Apple Silicon and Intel DMGs for the same product version. The macOS app is ad-hoc signed and is not notarized. Upgrade the paired app and server together, and retain the existing state and authentication files under the normal upgrade procedure.
