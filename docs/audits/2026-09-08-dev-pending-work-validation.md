# 미커밋 작업 개발 반영 검증 · 2026-09-08

기준은 dev의 `323d55c` 이후 원래 작업공간에 남아 있던 변경이다. 이 문서를
포함하는 커밋은 질문 처리·권한 검증·카드 및 네이티브 갱신 안정화와 그 조사
자료를 함께 반영한다. #69·#70의 최종 UI/도구 통합은 별도 초안
[PR #71](https://github.com/menaje/codex-mcp-bridge-for-chatgpt/pull/71)에 있으며,
이번 개발 반영으로 해당 PR의 완료 조건을 충족했다고 처리하지 않는다.

## 반영 범위

- 모든 CLI 설치본과 fresh/continue/fork 경로에 공통 권한 접수·실효 정책 검증을 적용한다.
  호환 계약을 확인한 기능만 제공하고, MCP form/URL 입력과 질문 출처를 검증한다.
- GPT 일반 질문 조회·응답, 사용자 질문 카드와 대화별 답변 저장·전달·소비 상태를 추가한다.
  SQLite schema 13과 만료·재시도·불확실한 전달의 처리 규칙을 포함한다.
- macOS 관리 터널에 loopback HTTP를 사용하고 네이티브/HTTP 요청의 실행 상태와
  종료 준비를 공유한다. 런타임·카드 읽기와 긴 감시 요청이 서로 막히는 경로를 보완한다.
- 현황 조회의 반복 읽기를 줄이고, 추가 정보 갱신 실패·미확인 상태·사용량 확인
  시각을 표시한다. 늦게 도착한 네이티브 설정 응답과 카드 재진입 응답을 처리한다.
- CLI 및 질문 조사 MD/JSON, 도구 설명 검토와 재현 스크립트를 보존한다.
  조사 당시의 미검증·가설 기록과 후속 검증 결과는 별도 문서로 구분한다.

보관 HTML 다섯 개에는 공백만 있는 줄이 남아 있다. 이 리소스는 기존 대화가
참조하는 내용 해시를 유지해야 하므로 수정하지 않았다. 릴리즈 검사는 해당
불변 스냅샷과 manifest의 일치를 확인하며, 소스 공백 검사는 별도로 통과했다.

브라우저 44개 시나리오는 실제 Chromium과 로컬 모의 ChatGPT 호스트를 사용한다.
실제 계정·모델·ChatGPT에서의 기존 증거는
[질문 후속 검증](2026-09-08-gpt-question-followup.md)에 보존했으며 이번에 재실행하지 않았다.
macOS 제외 항목은 명시적 live companion socket과 HTTPS pairing invitation이 필요한
선택 실행 검사다. 자동 테스트의 통과 수를 물리 Mac/실제 호스트 검사로 계산하지 않는다.

초기 검사에서 빌드와 동시에 시작한 실행기 검사가 조기 종료했으며 빌드 완료 후
전체 750개가 통과했다. 별도 출력 계약 검사에서는 앞선 Fast 필드 추가로 앱 전용
스키마가 480 bytes 증가한 사실을 확인하고 감사 기준을 갱신했다. 원래 번역
카탈로그의 네 개 추가 문자열은 유지하면서 무관한 전체 서식 변경을 제거했다.

`output/**`의 과거 빌드 복사본이 테스트 검색에 섞이는 문제도 확인했다.
기본 명령을 `vitest run --dir test --maxWorkers=4`로 수정하여 현재 저장소의
테스트만 실행한다. 이전 감사의 더 큰 실행 수는 현재 고유 테스트 수가 아니다.
기준 갱신 후 출력 계약 15개 테스트도 별도로 통과했다. 24개 MCP 작업을 준비하는
현황 조회 회귀 검사가 병행 부하에서 기본 5초 제한을 넘은 점을 확인하고, 인접한
대량 준비 검사와 같은 15초 제한을 적용했다. 조회 횟수와 갱신 검증은 유지했다.
