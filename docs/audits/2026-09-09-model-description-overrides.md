검토일: 2026-09-09. 대상: [자동 모드 모델 설명 편집](https://github.com/menaje/codex-mcp-bridge-for-chatgpt/issues/83).

개발 브랜치 기준 커밋은 `97787950c80733926072977a08615cde63eb1a1e`이다.
모델 설명 기능은 별도 작업 브랜치에서 구현했다.

## 완료 조건

| 조건 | 구현 및 확인 |
| --- | --- |
| 사용자 설명만 저장 | `modelDescriptionOverrides`에 모델 ID와 사용자 문구만 저장한다. 파일 재로딩과 실제 SQLite 설정 경로에서 유지되며, 예전 설정은 빈 맵으로 읽고 리비전을 올리지 않는다. |
| 자동 모드에만 적용 | `codex_models`에서 사용자 설명을 우선 적용하고 `descriptionSource: "user"`로 표시한다. 고정 모드에서는 공식 설명을 사용하고 사용자 문구는 보관한다. |
| 공식 설명 조회 방식 유지 | 카탈로그 수집·캐시·실패 대체 코드는 변경하지 않았다. 브라우저 검사에서 기존 캐시가 유지되고 유효기간 경과 후 받은 공식 설명으로 비교·복원이 이루어짐을 확인했다. |
| 편집·저장·취소·복원 | 앱과 카드에 공식/사용자 설명 표시, 현재 문구가 채워진 편집창, 명시적 저장·취소, 공식 설명 비교·복원을 제공한다. 공백은 삭제로 처리하며, 공식 문구를 수정 없이 저장하면 사본을 만들지 않는다. |
| 공유 설정 및 충돌 | 설명 전용 패치가 다른 일반 설정을 함께 저장하지 않는다. 리비전 충돌 시 입력을 유지하고 현재 저장된 설명을 보여 준 뒤 명시적 재시도를 받는다. 재시도는 다른 모델의 최신 설명도 보존한다. |
| 카탈로그 변경과 모델 미노출 | 공식 설명이 바뀌어도 사용자 문구를 보존한다. 현재 목록에서 빠진 모델의 저장값과 진행 중인 편집을 유지한다. 설명 때문에 그 모델이 실행 가능해지지는 않는다. |
| 실행 정책 및 텍스트 표시 | 실행 정책 식별자, 작업 도구 정의, 허용 모델·추론·접근 범위를 변경하지 않는다. 사용자 문구는 일반 텍스트로 표시하며 스크립트 문자열 실행을 차단한다. |

## 검증 범위

브라우저 검사는 실제 렌더링과 사용자 입력을 실행하고, 인메모리 MCP 연결과 격리된
SQLite 설정 저장소를 사용한다. 상류 모델 카탈로그와 시계는 테스트 대역이다.
네이티브 저장 검사는 테스트 클라이언트를 사용하며 앱 UI의 컴파일과 편집 상태를
검증한다. 두 선택 실행 검사는 실제 로컬 소켓과 HTTPS 페어링에 관한 항목이다.

이 검증은 실행 중인 운영 앱의 설정을 변경하거나 실제 모델 작업을 시작하지 않는다.
운영 앱 배포와 ChatGPT 연결의 새 카드 채택은 별도 적용 단계다. 브라우저 보고서와
화면 캡처는 `output/playwright/model-descriptions/`에, 기존 카드 회귀 보고서는
`output/playwright/card-resilience/dist/report-settings.json`에 생성된다.

사용법과 저장 의미는 [모델 선택 문서](../model-selection.md#user-model-descriptions)에 정리했다.
