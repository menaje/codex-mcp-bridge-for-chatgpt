# Issue #75 완료 검토

검토일: 2026-09-09. 대상: [Ultra 정책 및 모델 선택 정보 출처](https://github.com/menaje/codex-mcp-bridge-for-chatgpt/issues/75).

기준 커밋 `c6e24ed525f9a4d4e9d4ac993166f9c3bfb52c5f`에서 별도 작업 트리를 만들고
이번 이슈의 변경만 적용했다. 접근 정책과 대시보드의 다른 미커밋 변경은 포함하지 않았다.
검토 결과, 아래 요구 범위에서 추가 수정을 요구하는 결함은 발견하지 못했다.

## 완료 조건 대조

| 조건 | 구현과 확인 결과 |
| --- | --- |
| 자동 모드에서 기존 Ultra를 유지한 채 OFF 저장 | 명시적 사용자 선택은 보존하고, 현재 실행 가능 조합을 계산할 때 Ultra를 제외한다. 정책·설정 파일 재로딩·MCP 저장 검사에서 확인했다. |
| 전체 카탈로그·명시적 목록·고정 모드 처리 | 전체 카탈로그는 필터링하고, 명시적 목록은 비활성 선택을 보존한다. 고정 Ultra/OFF는 다른 추론 수준을 선택할 때까지 저장을 거부한다. |
| 실행 가능한 조합이 없는 경우 | 빈 실행 목록과 안내를 반환하고 실행을 차단한다. 허용하지 않은 조합을 추가하지 않으며, Ultra만 남은 자동 정책은 Fast가 켜져 있어도 저장할 수 있다. |
| 오래된 직접 선택과 스레드 상속 우회 차단 | 직접 Ultra 요청 및 Ultra 스레드의 continue/fork가 실행 백엔드 호출 전에 거부됨을 확인했다. 재활성화 후 같은 스레드의 상속 실행이 복구된다. |
| 카드·macOS 앱의 안내 일치 | 9개 언어에서 Ultra 허용 범위, 비활성 이유, 고정 충돌, 빈 실행 범위 문구가 일치한다. 카드의 표시·저장과 앱의 자동 저장 경로를 검증했다. |
| 위임 제어의 보장 범위 명확화 | 설정 이름을 “Ultra 추론 허용”으로 좁혔다. 기존 `allowDelegation` 필드는 호환성을 위해 유지한다. 모든 에이전트 기능을 차단한다는 약속은 제거했다. |
| 정보 출처 구분 | GPT용 모델·추론·서비스 티어 설명은 Codex 카탈로그 설명을 유지한다. 도구 설명과 문서에서 UI 번역, 브리지 실행 정책, GPT의 다른 대화·호스트 컨텍스트를 구분했다. 모델별 추천표를 추가하지 않았다. |

확인하는 검사를 추가했다.

## 검증 범위

브라우저는 실제 렌더링과 사용자 입력을 실행하되 카탈로그·저장 응답은 격리된 fixture를
사용했다. MCP 실행 백엔드와 네이티브 저장 클라이언트도 테스트 대역이다. 실행 중인
운영 브리지의 설정 변경과 실제 모델 호출은 이 검증 범위에 포함되지 않는다.

건너뛴 두 검사는 라이브 로컬 소켓 계약과 라이브 HTTPS 페어링 검사로, 이번 변경의
자동 저장·정책 검사와 별개다. 이 기록은 코드 구현과 회귀 검증의 완료 근거이며,
운영 앱 배포나 모든 형태의 Codex 하위 에이전트 위임 차단을 실측했다는 뜻은 아니다.

정책의 상세 의미와 출처는 [모델 선택 문서](../model-selection.md)에 정리했다.
