# 메뉴바·현황 카드 공통 요약 — #78

[이슈 #78](https://github.com/menaje/codex-mcp-bridge-for-chatgpt/issues/78)의
소스 구현과 로컬 검증을 완료했으며, 완료 검토에서 발견한 두 집계 오류를 수정했다. 기존 개발 디렉터리의 다른 미완료 변경을
유지했으며, 운영 브리지 재시작·앱 설치·ChatGPT 연결 갱신은 수행하지 않았다.

## 표시와 집계

메뉴바와 새 현황 카드는 **실행 중 / 응답 필요 / 문제**를 같은 서버 집계로
표시한다. 입력과 승인 대기는 Agent마다 한 번만 응답 필요로 집계한다.
문제는 최신 실패·중단·종료 실패·실행 상태 확인 불가·추적 유실을 사용하고,
정상 응답 대기와 보관된 Agent는 제외한다. 이후 실행으로 해소된 실패는
문제 수에 남기지 않고 실행 이력으로 보존한다. 메뉴바 연결 상태에서도
입력·승인 대기만 있는 경우를 장애로 취급하지 않는다.

최종 디자인 요청에 따라 이전 메뉴바처럼 아이콘·이름 아래 큰 숫자를 놓는
3열 타일 대시보드를 양쪽에 적용했다. 밝은/어두운 색상과 360px 카드 폭에서도
같은 배치를 유지한다. 요약을 누르면 해당 상태의 목록을 조회하고,
전체 보기로 돌아갈 수 있다.
숫자는 선택된 대화 범위 전체에서 먼저 계산하므로 필터나 첫 페이지 크기에
따라 줄어들지 않는다. 메뉴바는 선택 서버 전체를 조회한다. 카드의 이 대화 /
전체 현황 선택은 #76의 동작을 유지한다.

유휴 수와 별도 목록을 제거했다. 과거 실행이 있는 유휴 Agent는 실행 기록에
포함하고, 실행하지 않은 유휴 Agent는 표시하지 않는다. 응답 필요와 문제를
현재 작업에서 먼저 표시하며, 종료 중 배지는 유지한다. 백그라운드 프로세스는
별도 보조 행으로 조회할 수 있고 미확인·확인 지연 안내도 유지한다.
프로젝트·대화·누적 기록 수를 상단에서 제거했지만 작업 문맥·대화 링크·
각 실행의 모델·이력·사용량·상세 제어는 유지했다.

## 구현과 호환성

- `src/tools.ts`의 표시용 조회에서 중복 제거, 공통 집계, 상태 필터와
  실행 기록 통합을 수행한다. App-private 및 companion 입력에 선택적
  `statusFilter`를 추가했다.
- 현재 카드와 네이티브 클라이언트는 `statusFilter: all`로 시작한다.
  이 인수를 생략하는 이전 카드는 기존 active/recent/idle 페이지를 받는다.
  새 필터로 전환하면 이전 비동기 응답과 추가 페이지가 새 화면에 섞이지 않는다.
- 카드 계약은 generation **24**이며 현재 리소스는
  `ui://codex-mcp-bridge/dashboard/cea27ba2992d.html`이다.
  HTML은 **144,111바이트**로 144 KiB 예산 이내다.
- 병합 기준 dev에 등록되어 있던 **159개** 불변 리소스의 URI·메타데이터·등록을
  보존했고, 기존 추적 HTML 파일은 수정하지 않았다. 릴리스 검사에서
  리소스 내용과 메타데이터의 해시도 검증했다.
- 네이티브 클라이언트와 서버는 함께 갱신해야 한다. 새 클라이언트가
  `statusFilter`를 모르는 오래된 서버로 자동 협상하는 기능은 추가하지 않았다.
- Agent/Job/DB 보존, App Server 연결 해제, Codex 앱 인계와 캐시 정책은
  변경하지 않았다. 해당 작업은 #80의 범위다.

## 완료 검토에서 수정한 두 경우

1. 실패한 실행이 남긴 백그라운드 프로세스가 있으면 대표 행의 상태가
   백그라운드 실행으로 바뀌면서 문제 수가 0이 되는 경우를 재현했다.
   현재 화면은 실패 상태와 문제 집계를 유지하고, 프로세스 수·필터를 별도로
   제공한다. 이전 카드의 원래 대표 행은 유지한다.
2. 과거 실패에 늦은 갱신이 도착하면, 성공한 재실행이 먼저 보존 요약으로
   이동하고 오래된 실패의 전체 Job이 남을 수 있었다. 최신 실행을 전체 Job과
   보존 요약의 실행 시작 시각으로 비교하고, 모든 실행이 요약으로 이동한
   이후에도 같은 기준을 사용하도록 수정했다. 시작 시각 없는 이전 요약은
   기존 갱신 시각을 호환 기준으로 사용한다.

두 검사는 수정 전 실패하고 수정 후 통과했다. 이는 표시용 최신 실행 선택의
수정이며 DB 저장 구조나 보존 기간을 바꾸지 않는다. dev 통합에는 요약·이력·
필터와 연결된 화면 내 상세 제어 및 초안 보존을 포함한다. 중앙 실행 정책 등
다른 미완료 변경은 원래 작업 디렉터리에 남겨 두고 병합에서 제외했다.

## 검증

- 최신 dev(`15bcd99`)에서 분리한 최종 통합 소스의 전체 **64개 파일,
  815개 테스트 통과**: `npx vitest run --dir test --maxWorkers=1`.
  기본 제한 시간을 늘리거나 테스트를 제외하지 않았다.
- `npm run build`, `npm run validate:fast` 통과. App Server 호환성은
  CLI **0.153.3**, JSON 416개 및 TypeScript 827개 스키마로 확인했다.
- 네이티브 엄격한 동시성·경고 검사: **112개 실행, 기존 환경 조건 2개 스킵,
  실패 0개**. 정상 입력/승인 대기와 실제 문제의 메뉴바 상태 구분을 포함한다.
- TypeScript 타입 검사, 릴리스 정책/리소스 검사, 공백 검사 통과.
- macOS **589개 문자열, 9개 언어** 검사 통과. 새 요약·필터·현재 작업
  문구가 카드와 네이티브에서 9개 언어 모두 일치함을 확인했다.
- 새 요약 브라우저 검사 **9개 그룹** 통과: 세 요약, 네 필터, 범위 전체
  수치, 새로고침, 실행 기록 추가 페이지, 늦은 응답, 빈 화면, 종료 중,
  백그라운드 미확인. `npm run test:dashboard-summary-browser`로 재현한다.
- 기존 범위 전환 검사 **7개 그룹**, 입력 제어 **4개 시나리오**,
  중단 제어 **6개 시나리오** 통과. 입력 초안·포커스 보존, 상세 접기/전환,
  사라진 대상 정리와 정확한 제어 대상 전달을 포함한다.
- 배포용 빌드의 Dashboard 복원·오류 처리 **9개 시나리오**, 기존 불변 카드의
  호환 동작 **4개 시나리오**도 통과했다.
- 최종 타일 디자인 반영 후 빌드, 번역·리소스 호환 **23개 테스트**,
  요약 브라우저 **9개 그룹**을 다시 통과했다. 사용하지 않는 이전 요약
  번역만 새 카드 번들에서 제외했고, 이전 불변 HTML은 보존했다.
- 카드의 밝은/어두운 화면 및 360px 모바일 화면을 직접 확인했다.
  네이티브는 운영 서비스와 분리된 합성 스냅샷으로 실제 SwiftUI 뷰의
  밝은/어두운 요약 레이아웃을 캡처해 확인했다.

초기 검사 명령은 `output/` 아래 예전 빌드 복사본까지 발견해 중복 실행과
시간 초과를 일으켰다. 위 최종 명령은 `--dir test`로 현재 소스에 한정하며,
기본 제한 시간과 전체 테스트를 유지한 최종 통합 검사에서도 모두 통과했다.

브라우저 결과는 `output/playwright/dashboard-summary-regression/`과
`output/playwright/dashboard-scope-regression/`에 있다. 이는 로컬 모의 호스트
검증이며 실제 ChatGPT 호스트 검증이나 운영 배포 완료를 의미하지 않는다.
이 문서의 완료 범위는 검증된 소스의 dev 통합이며, 운영 앱·서버 교체와 실제 ChatGPT 호스트 확인은 별도다.
