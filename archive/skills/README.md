# Archived ChatGPT skill documents

This directory preserves the retired ChatGPT skill source for historical
reference only. ChatGPT does not consume these files, and they are not an
active installation or distribution surface.

Everything below `archive/skills/` is intentionally excluded from:

- the npm package;
- the native macOS app bundle and DMG;
- GitHub Actions build artifacts;
- GitHub prerelease and stable release assets.

Do not add packaging or installation automation for these files unless the
product gains a supported consumer and the distribution decision is explicitly
revisited.
